# Banner3 Block

## Overview
Banner3 is a custom promotional banner block used to display marketing content.

## Configuration

### Fields
- title
- overline
- description
- image
- CTA text
- CTA link

## Behavior
- Displays banner content.
- Supports responsive layouts.
- Renders authored content from Universal Editor.

## Integration
- Universal Editor component.
- Uses component-definition.json
- Uses component-models.json
- Uses component-filters.json

## Error Handling
- Empty title displays no heading.
- Missing image falls back to default styling.
